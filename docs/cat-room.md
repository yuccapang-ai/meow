# 猫咪房间与收集

房间为默认首页。甜甜圈猫默认入住，可散步和睡觉；其余八只摸鱼猫每种各自累计 30 只后自动入住，同时开放散步和睡觉。每种猫各自达到 50 只后开放专属动作。已有分猫计数直接适用新门槛，不清空存档。

房间高度保持原来大小、铺满视口，仅将背景的横向长度缩短为原来的一半（最小不小于视口宽度）。猫咪和界面按钮维持原尺寸，仍可横向滚动和按分区定位。

房间顶部「猫咪收集」查看九张进度卡。卡片上的已解锁动作可点选，返回房间定位到对应猫并播放动作；未解锁动作禁用。房间里的猫会自主散步、睡觉，以及播放已解锁的专属动作。点击睡觉中的猫可以叫醒它，「找猫咪」循环定位所有住户。

猫咪入住时分配互不重叠的落点，行走前检查路线，每帧检查实际移动路段。遇到其他猫会避让，空间不足时停下等待，再选择路线；睡觉和专属动作同样保留身体间距。房间拥挤时利用地板前后排，极小窗口才适当缩小猫咪以容纳全部住户。

「去养猫」「去收集猫咪」默认使用摸鱼猫套系。选择幸运猫时仍可切换其他已解锁套系。每局正常结算后使用 engine.tally(state).counts 的九项明细入账（暂存加棋盘剩余）；不同套系分开记录，其他套系不推进本期九只摸鱼猫的进度。重播、重复结算和中途退出均不重复增加收集。

本地收集存档键 `ttddp.catCollection.v1`，独立于原总纪录 `ttddp.best.v2`。旧存档仅有总数，无法恢复分猫明细，因此保留旧总纪录，分猫计数从本版本后的正常对局开始累计。存储不可用时仍维持当前会话进度。

代码：`cat-collection.js`（目录与存档）、`collection-view.js`（进度卡）、`room-residents.js`（独立住户与动作）、`room.js`（镜头与房间生命周期）。动作使用 16 帧图集：8 散步、4 睡觉、4 专属动作；散步帧由实际位移驱动，睡醒逆序衔接。后台、离开房间时暂停，回来不补走离线时间；系统减少动画偏好下保持静止。

素材与完整提示词见 `myasset/room-cats-v1/README.md`。各猫图集按解锁加载，不预加载九只大图。
